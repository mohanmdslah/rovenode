ROVE mobile wallet resilience (2026-09-15): the wallet layer must stay usable on the Huawei phones that make up much of the audience, where MetaMask cannot be installed and the wallet is usually reached through a wallet app's own WebView. Keep these rules when touching `src/lib/wallet.js`, `src/lib/wallet-session.js` or the header flow. Wallet detection is continuous, never a one-shot probe: `watchInjectedWallet` keeps listening for `ethereum#initialized`, EIP-6963 `announceProvider` and late `window.ethereum` injection for the life of the page, because a Huawei WebView can inject seconds after load and the connect button must not be a silent no-op. Tapping connect with no wallet must always surface a localized reason and stay retryable; the missing-wallet copy tells phone users to open the page in a wallet app browser rather than in the system browser, and a non-HTTPS page reports that wallets will not inject. Every EIP-1193 request is bounded by a deadline (15s reads, 90s prompts) and the serialization queue is released on timeout, so a wedged bridge can never freeze the session or the reads queued behind it; prompts jump ahead of reads so a wallet UI still opens on the user's tap. Wallets that only expose `send`/`sendAsync` are adapted, and `window.ethereum.providers` is honoured. A manual disconnect must never disable the connect button until reload, and an interactive connect must supersede a slow passive probe. `ensureWalletChain` in `src/lib/wallet.js` is the single chain-switch implementation used by both the session and `ensureBscChain`; it re-reads the chain after switching because mobile wallets report the old chain briefly, and it still never supplies a hard-coded RPC. The production bundle targets `chrome69`/`safari14`/`firefox68`/`edge79` in `vite.config.mjs` and `src/lib/polyfills.js` is imported first in `src/main.jsx`, because Vite's default target emits ES2020 syntax and a missing runtime API (for example `Promise.allSettled` in the page loader) blanks the page on those engines before React can mount. Re-verify with `node qa/huawei-wallet-check.mjs` and `test`, and never lower the bundle target back without checking that `?.` and `??` are absent from `dist`.
